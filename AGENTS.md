# Project Content & Git Rules (STRICT)

1. **Use ONLY Exact Client Content — Zero AI-Written Copy**
   - NEVER invent, paraphrase, summarize, expand, or add a single word, bio, heading, subheading, tag, or description of your own.
   - Use ONLY the exact verbatim text, numbers, and links provided by the user/client.
   - If any text, bio, link, or detail is missing or unclear, **STOP and ASK the user first** before adding anything.
   - Do not reuse unverified/AI-written text from existing JS arrays or old sections without confirming with the user.

2. **Git Workflow**
   - Do **NOT** run `git push`. Commit locally (and rebuild `asci-website-package.zip` with `python scratch/sync_and_zip.py`) and let the user push with their own Git account.
